# Installing Git
 
Before you can start using Git commands, you need to install it.
 
### Linux
 
Run the following commands in your terminal:
 
```bash
sudo apt update
sudo apt install git
```
 
### Windows
 
Follow this video tutorial to install Git: [How to Install Git on Windows](https://www.youtube.com/watch?v=hC0IRTdbV7o)
