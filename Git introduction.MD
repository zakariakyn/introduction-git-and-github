# Introduction to Git

Git is a version control system created by Linus Torvalds in 2005, originally to manage and enable collaboration on large codebases like the Linux kernel.

Git supports projects of any size — from a single developer to teams of thousands.

Git is free and open source.

Git works fully offline for most operations — such as committing, branching, and viewing history — and only needs a network connection when syncing with a remote repository, for example through SSH, HTTP/HTTPS, or the Git protocol.

Git is often referred to as a Source Code Management (SCM) tool.
